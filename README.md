# 🐕 Pardo Agenda v5.1

Tu mascota virtual te ayuda a organizarte

## 📋 Descripción

Pardo Agenda es una aplicación web completa de organización personal con mascota virtual interactiva. Incluye calendario, diario, hábitos, notas, deseos, frases, estadísticas, logros, y mucho más.

## 🚀 Características

### 🔐 Autenticación
- Registro y login con JWT
- Recuperación de contraseña
- PostgreSQL para persistencia

### 📅 Organización
- Calendario con tareas por fecha
- Hábitos con rastreador semanal
- Notas con 12 colores e imágenes
- Lista de deseos con categorías
- Recordatorios con hora programada

### 📔 Personal
- Diario con moods y gráfico
- Sistema de logros (7 niveles + 12 logros)
- Frases motivacionales
- Rachas diarias con mejor racha
- Multi-idioma (ES/EN/FR)

### 🔧 Herramientas
- Pomodoro
- Lista de compras
- Contactos
- Calculadora
- Enlaces útiles
- Asistente IA con sugerencias

### 📊 Datos
- Dashboard con gráficos
- Estadísticas de productividad
- Exportar/Importar JSON
- Notificaciones

### 🎨 Personalización
- 6 temas de color
- Modo oscuro
- Splash screen

### 📱 PWA
- Instalable en móvil
- Service Worker
- Funcionamiento offline

### 🔒 Privacidad
- CookieBanner RGPD
- Política de privacidad
- Términos de uso

### 🎮 Extra
- Mini-juego "Atrapa a Pardo"
- Spotify integrado
- Menú móvil con categorías

## 🛠️ Tecnologías

- **Frontend:** React 18, React Router, Context API
- **Backend:** Node.js, Express, JWT, bcryptjs
- **Base de datos:** PostgreSQL 16
- **Contenedores:** Docker Compose
- **Caché:** Redis
- **PWA:** Service Worker + Manifest

## 📦 Instalación

```bash
git clone https://github.com/urukaisk-maker/pardo-agenda.git
cd pardo-agenda
docker-compose up -d --build
```
