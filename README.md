# 🐕 Pardo Agenda

Tu mascota virtual te ayuda a organizarte

## 📋 Descripción

Pardo Agenda es una aplicación web completa de organización personal con una mascota virtual interactiva. Incluye calendario, diario, hábitos, notas, deseos, frases motivacionales, servicios útiles y más.

## 🚀 Características

- 🔐 **Autenticación** - Registro y login con JWT
- 📅 **Calendario** - Vista mensual con tareas por fecha
- 📔 **Diario** - Entradas con moods y Spotify integrado
- ✅ **Hábitos** - Rastreador semanal
- 📝 **Notas** - Con colores personalizables
- ⭐ **Deseos** - Lista con categorías
- 💬 **Frases** - Motivacionales con navegación
- 🔧 **Servicios** - Enlaces útiles
- 🏆 **Logros** - Sistema de XP y niveles
- 📊 **Estadísticas** - Gráficos de productividad
- 📤 **Exportar** - Backup JSON
- 📱 **PWA** - Instalable en móvil

## 🛠️ Tecnologías

- **Frontend:** React 18, React Router, Context API
- **Backend:** Node.js, Express, JWT, bcryptjs
- **Base de datos:** PostgreSQL 16
- **Contenedores:** Docker Compose
- **Caché:** Redis
- **Almacenamiento:** MinIO

## 📦 Instalación

```bash
# Clonar repositorio
git clone <repo-url>
cd pardo-agenda

# Levantar servicios
docker-compose up -d --build

# Acceder
# Frontend: http://localhost:3000
# Backend: http://localhost:5000
# PGAdmin: http://localhost:8080
# Adminer: http://localhost:8081
```
